# Как выложить приложение в интернет и поставить на iPhone

Это нужно сделать один раз. Займёт минут 15–20. Всё делается с компьютера, кроме последнего шага.

Что получится: у приложения появится своя ссылка вида `https://твоё-имя.github.io/study-planner/`. Ты откроешь её на iPhone и добавишь на экран «Домой».

> Твои данные (план, темы, словарь) на GitHub **не попадают**. Они хранятся только в памяти телефона. На GitHub лежит только сам код приложения.

---

## Шаг 1. Зарегистрироваться на GitHub (делаешь сама)

1. Открой https://github.com и нажми **Sign up** («Зарегистрироваться»).
2. Введи почту, придумай пароль и имя пользователя. Имя станет частью ссылки на приложение, поэтому лучше простое и латиницей, например `my-study-2026`.
3. Подтверди почту: на неё придёт письмо с кодом.
4. Когда GitHub спросит про тариф, выбирай **Free** (бесплатный).

## Шаг 2. Создать «репозиторий» (делаешь сама)

Репозиторий — это просто папка на GitHub, где лежат файлы приложения.

1. Нажми **+** вверху справа → **New repository**.
2. **Repository name**: `study-planner` (латиницей, без пробелов).
3. Выбери **Public** (публичный). Для бесплатных страниц так нужно, а секретов в нём нет.
4. Остальные галочки не трогай. Нажми зелёную кнопку **Create repository**.

## Шаг 3. Загрузить файлы приложения (делаешь сама)

1. На странице нового репозитория нажми ссылку **uploading an existing file**.
2. Открой на компьютере папку с приложением. Выдели **всё её содержимое**: файлы `index.html`, `manifest.json`, `sw.js` и папки `css`, `js`, `icons` (Ctrl+A внутри папки).
3. Перетащи выделенное в окно браузера на GitHub. Саму папку-контейнер перетаскивать не нужно, только то, что в ней лежит.
4. Подожди, пока всё загрузится, и убедись, что в списке видны `index.html` и папки `css`, `js`, `icons`.
5. Внизу нажми зелёную кнопку **Commit changes**.

Проверка: на главной странице репозитория `index.html` должен лежать сразу в списке файлов, а не внутри другой папки.

## Шаг 4. Включить GitHub Pages (делаешь сама)

1. В репозитории нажми вкладку **Settings** (с шестерёнкой, справа от Insights).
2. В меню слева выбери **Pages**.
3. В блоке **Build and deployment** → **Source** выбери **Deploy from a branch**.
4. Ниже в **Branch** выбери `main`, рядом папку `/ (root)`, и нажми **Save**.
5. Подожди 1–3 минуты и обнови страницу (F5). Сверху появится надпись **Your site is live at …** со ссылкой. Это и есть адрес твоего приложения.
6. Открой ссылку и проверь, что приложение загрузилось.

Если вместо приложения «404»: подожди ещё пару минут. Если не помогло, вернись к проверке в конце шага 3.

## Шаг 5. Поставить на iPhone (делаешь сама)

1. Отправь себе ссылку, например в Telegram «Избранное» или в Заметки, и открой её на iPhone **в Safari** (не внутри Telegram).
2. Нажми кнопку **Поделиться** (квадрат со стрелкой вверх внизу экрана).
3. Пролистай меню вниз и выбери **На экран «Домой»**.
4. Нажми **Добавить**. Иконка появится на экране.
5. Первый раз открой приложение при включённом интернете: тогда оно сохранит себя в памяти и дальше будет работать и без сети.
6. Дальше открывай только с иконки.

Остальную настройку телефона (режим «Фокусирование», команда «Deep Work», календарь) смотри в самом приложении: значок настроек вверху → **Как настроить**.

---

## Как обновить приложение позже

1. Зайди в репозиторий → **Add file** → **Upload files**.
2. Перетащи изменённые файлы, названия те же. Нажми **Commit changes**.
3. Через минуту открой приложение при включённом интернете. Если видишь старую версию, закрой его полностью (смахни вверх из переключателя приложений) и открой снова.

## Если что-то пошло не так

- **Нет кнопки «На экран “Домой”»** — ты открыла ссылку не в Safari.
- **Пропали данные** — их можно вернуть из резервной копии: **Ещё** → **Резервная копия** → **Импорт**. Делай экспорт хотя бы раз в неделю и сохраняй файл в «Файлы».
- **Удалила иконку с экрана** — данные вместе с ней стираются. Сначала экспортируй копию.
